# Marketers Unmuted CRM

CRM for **Marketers Unmuted**, the CanadianSME Media Group podcast, website and community for marketers.

**Phase 1: demo.** All people and companies are invented. Changes are saved in your browser only.

## Pages
Dashboard · Leads · Guests & episodes · Follow-ups · Partnerships · Sponsors & deals · Content · Community · Team & setup

## Run locally
No build step. Serve the folder with any static server:

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
